# Investigación y Análisis: Principios SOLID

## Descripción

Este proyecto contiene una investigación sobre los principios SOLID aplicados a la Programación Orientada a Objetos.

Incluye la explicación de cada principio:

- Single Responsibility Principle (SRP)
- Open/Closed Principle (OCP)
- Liskov Substitution Principle (LSP)
- Interface Segregation Principle (ISP)
- Dependency Inversion Principle (DIP)

## Contenido

- Investigación teórica sobre SOLID.
- Conceptos clave de diseño de software.
- Ejemplos de refactorización de código.
- Análisis de ventajas y problemas de diseño.
